# Portfólio alternativo de Marcelo Andrade

Cópia para comparação, com composição própria inspirada em https://landing-page-mate.vercel.app/. A produção da branch main permanece preservada.

## Direção visual
Tipografia ampla, galeria inclinada com capturas reais, seções claras e escuras, ciano e Manrope. Sem código, vídeos, fotografias, fonte ou logotipo da agência. Mantém projetos, contatos, mensagem de WhatsApp e páginas internas de Marcelo. Projetos demonstrativos e planejados continuam identificados.

Watermelon UI: Hero 15, Hero 20 e Hero 22 comparados; fonte de Hero 15 consultada para hierarquia de ações. CSS próprio, sem dependências novas.

## Executar
Use `npm ci`, `npm run dev` e `npm run build`.

Localmente, node_modules é uma junction para as dependências do portfólio original. Não remover seu destino. next.config.mjs adapta a raiz do Turbopack; checkouts comuns usam dependências próprias.

## Comparação
Manter na branch alternativa e em deployment Preview. Noindex ativado; canonical preserva o endereço oficial. Não promover para produção sem decisão do usuário.
